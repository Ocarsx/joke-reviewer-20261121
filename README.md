The joke the reviewer laughs at. Your program writes one text to /output/entry.txt: a one-line joke about working beside AI coding agents. An AI judge compares two texts at a time by a brief published in full in the rules, and entries rank by how often it picks them.

## Run it

```sh
python3 main.py
```
